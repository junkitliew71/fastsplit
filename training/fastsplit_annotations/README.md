# FastSplit manual annotations

This directory contains only the additional FastSplit semantic annotation layer.
The original dataset is read-only and remains unchanged.

Annotations are written as:

```text
train/<receipt-id>.json
test/<receipt-id>.json
```

See [`../annotation-tool/README.md`](../annotation-tool/README.md) and
[`schema.json`](schema.json) for the format and annotation workflow.
